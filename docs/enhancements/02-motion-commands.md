# Motion and command center

A technical workspace console exposes Cmd/Ctrl+K navigation, page actions, new-task creation and project-wide work-item search. Native dialog semantics provide Escape handling, focus containment and focus return. Arrow keys move through results. Motion adds staged entry, card lift, dialog reveal and animated metric bars. The operating system reduced-motion preference is respected.

Manual checks: open from the visible button and shortcut, search a task, open it, navigate with arrows/Enter, close with Escape and confirm focus returns. Test reduced motion and mobile widths.
