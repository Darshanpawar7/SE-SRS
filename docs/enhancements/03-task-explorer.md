# Task explorer and CSV

Work items adds a dense table with explicit selected-sprint/project scope, combined text/status/priority/owner filters, deterministic sorting and visible-row totals. Titles open the existing edit flow. CSV exports only visible records, quotes delimiters/newlines and neutralises spreadsheet formula prefixes. Exports stay on this device. Project scope includes unscheduled tasks. No schema change is needed.

Verify filters in combination, empty results, task edits, selected sprint changes, mobile horizontal scrolling and opening the exported CSV. This is a proposed product enhancement, not a claim that the original sprint required it.
