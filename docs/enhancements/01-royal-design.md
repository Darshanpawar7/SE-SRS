# Royal workspace design

Plum navigation, warm ivory workspace, champagne details and forest semantic accents replace the original neon glass styling. Serif display headings pair with medium-weight system sans UI text. All fonts are local: no third-party font request is needed. Shared components, forms, sign-in, navigation and responsive layouts use the same palette. A skip link and current-page navigation state improve keyboard orientation.

Review at 390px, 768px and 1440px; inspect board scrolling, chart dates, forms and dropdown contrast. No accessibility score is claimed. Existing functionality and storage formats are preserved.
