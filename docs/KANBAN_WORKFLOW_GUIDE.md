# Kanban Workflow & UI Module
**Owner:** DHATRI SHIVAPRASAD (PES2UG24CS158) — Frontend Lead

## Features Implemented:
1. **Interactive 5-Column Lifecycle:**
   - `Backlog`: New ideas and unrefined user stories.
   - `To Do`: Ready for active development.
   - `In Progress`: Currently being worked on.
   - `Code Review`: Pull request or peer review in progress.
   - `Done`: Tested and accepted.
2. **HTML5 Drag-and-Drop:**
   - Native drag events (`onDragStart`, `onDragOver`, `onDrop`) for fluid 60fps card movement.
   - Visual drop zones with active highlight border.
3. **Agile Task Creation Modal:**
   - Supports title, description, workflow stage, priority, story points, assignee, and tags.
4. **Multi-Dimensional Search & Filtering:**
   - Filter by assignee, priority level, and substring query.
